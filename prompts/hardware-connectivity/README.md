# Hardware Connectivity

Prompts for connecting to, configuring, and controlling hardware from MATLAB.

## Prompts in this Category

### [Control Function Generator Using VISA Interface](visa-function-generator-control.md)
Generate MATLAB code to control function generators using the `visadev` interface with SCPI commands. Covers instrument connection, waveform configuration (sine, sweep, arbitrary), and robust error handling.

**Tags:** `matlab` `instrument` `visa` `function-generator` `keysight` `rohde-schwarz` `scpi` `instrument-control`
**Release:** R2021a+, Requires Instrument Control Toolbox&trade;

### [RF Signal Generator Workflow](rf-signal-generator-workflow.md)
Connect, configure, and generate IQ waveforms using the Quick-Control RF Signal Generator (`rfsiggen`) interface. Includes resource/driver discovery, IQ waveform download, and RF transmission.

**Tags:** `matlab` `instrument` `rf-instrument` `signal-generator` `keysight` `rohde-schwarz` `quick-control` `rfsiggen`
**Release:** R2017b+, Requires Instrument Control Toolbox&trade;
